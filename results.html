The key security risks associated with AI agents include: 1. **Inherent Non-Determinism**: AI agent behavior, especially that of large language models (LLMs), is inherently non-deterministic as it processes unstructured natural language and may make different decisions across runs. This contrasts with the deterministic requirements for enforcing security measures. 2. **Task-Specific Requirements**: Agent security needs to adapt based on both the user's task and the information gathered during execution, which can evolve over time as the agent interacts with its environment. Ensuring this requires automatic tracking of changes without constantly involving the user. 3. **Privilege Expansion**: Agents may need to expand their privileges to complete benign tasks. However, adversaries might exploit these mechanisms for malicious purposes, highlighting the tension between operational flexibility and security. 4. **Indirect Prompt Injection**: LLM-based systems are vulnerable to indirect prompt injection attacks, where malicious instructions embedded in untrusted data can trigger dangerous actions by the agent. This is a significant risk because traditional rule-based security measures may not be sufficient to address such dynamic and context-dependent threats. 5. **Non-Reliability of Judge Models**: Using another LLM as a judge model for security decisions can itself be manipulated by prompt injection, thus introducing further vulnerabilities. These risks manifest in various ways within LLM-based systems, necessitating robust, multi-layered defense strategies to mitigate them effectively.
